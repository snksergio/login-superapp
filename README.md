# Login SuperApp iGreen · protótipo

Protótipo navegável do fluxo completo de login do SuperApp iGreen: abertura com biometria, boas-vindas, login por CPF, primeiro acesso, cadastro do Eletroposto, aparelho novo e ajuda de segurança.

**Ver online:** https://snksergio.github.io/login-superapp/

À esquerda ficam os fluxos; à direita, as telas do fluxo escolhido. Os botões dentro do celular também funcionam, e a barra "Simular" embaixo do celular preenche os dados de teste.

Todos os dados são fictícios.
